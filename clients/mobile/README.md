# Annotated Mobile Client (Android & iOS)

The official cross-platform mobile companion for the **Annotated Network**, built with React Native and Expo.

---

## Capabilities
* **Pure OLED Pitch-Black (#000000) UI**: Consistent with the web and Roku TV clients.
* **Mobile Pass Handoff**: Point phone camera at the Roku TV QR code to immediately load and interact with the active note.
* **Supabase Real-Time Sync**: Instant live multi-emoji reactions (🔥 🤔 💡 💯 👎) and fact-check verification cards.
* **Android Share Target**: Registered with `SEND` intent filter to receive video links from the official YouTube and X apps.

---

## Getting Started

```bash
cd clients/mobile
npm install
npm run android   # Start on Android device / emulator
npm start         # Start Expo dev server
```
